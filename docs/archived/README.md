# 归档区

本目录收编活跃文档的退役内容：从原文档移出后不再随原文档进入每次任务 context，原文档只留一行指向本目录的指针。
当前收编对象：`docs/risks/` 下各清单的退役条目。
日后其它文档出现同类"要留档但不该再进 context"的内容时，同样归到这里，一类内容一个文件。

## risks 条目退役规则

- 某条坑的防线（guard 测试、checklist 检查项、工程修复）已落地且连续一个发布周期零复发：把该条目移入本目录对应域文件，并注明防线位置。
- 归档条目不算任务前必读，仅保留历史可查。
- 防线被拆除时，条目升回原清单正文（加在最上方）。
- 本规则只在本文件存一份，清单正文不复述。
