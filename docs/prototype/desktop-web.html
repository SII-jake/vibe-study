那和单利的差别在数学上怎么描述？

两者在数学上只差一个指数位置。

单利是线性函数，随 n 线性增长；复利是幂函数，随 n 指数增长。

3 
单利：F = P × (1 + r × n)
复利：F = P × (1 + r)^n

在 r 很小的近似下， (1 + r)^n ≈ 1 + r × n ，所以短期看不出差别；期数一多，幂函数就拉开了距离。
